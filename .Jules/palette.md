## 2024-05-18 - Missing ARIA labels in custom Button size="icon"\n**Learning:** The project custom `Button` component accepts `size="icon"` but lacks an automatic way to enforce an accessible name. This frequently leads to icon-only buttons missing `aria-label` attributes across different components (e.g. `Calendar`, `DailyLogger`, `App`).\n**Action:** When working on this app and using the custom `<Button size="icon">` pattern, always manually ensure `aria-label` is provided to maintain screen reader accessibility.
